Entry for the [make.fun](https://make.fun) competition
**"The Tired Dark Lord: A 100-Word Villain Monologue"**
(`u-kevin-the-tired-dark-lord-a-100-word-villain-58b4f3cb`).

## What it does

`main.ts` writes a single ~100-word monologue to `/output/entry.txt`,
spoken by a fantasy villain who is secretly very tired. The weariness
lives in the voice — the pauses, the half-finished sentences, the small
deflections — never in a plain statement that he is weary. He is still a
villain: twelve years of counting days on the walls, a seventh bell at
dusk, ships coming home from the Ashen Coast, and a hero at the door
with a sword and a prophecy.

## Run

```sh
node main.ts
```

The output directory comes from the `MAKEFUN_OUTPUT_DIR` environment
variable and falls back to `/output`. The program uses only the Node.js
standard library and writes `entry.txt` as UTF-8 text.
